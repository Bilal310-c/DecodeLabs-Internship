Project 1

A responsive frontend interface built to showcase project cards dynamically using semantic HTML, CSS, and Vanilla JavaScript.

Description

This project was built during my time at DecodeLabs. It focuses on organizing project data into structured card layouts using Flexbox and Grid, with Vanilla JavaScript handling the dynamic rendering of content on the page.

How to run

1. Clone this repository:
   git clone https://github.com/Bilal310-c/DecodeLabs-Internship.git

2. Open the project:
   Just open 'index.html' directly in your browser or launch it with the Live Server extension in VS Code.
